对应[开发文档](课题三仿真系统重构开发文档.md)中的总图。实体职责和接口功能在正文说明，此处保留资料出处及适用范围。资料支持典型设备功能和接口，具体功能拆分、组网和无线选配属于本项目仿真配置。

## 1. 接口依据

### 1.1 过程层分类依据

IEC的变电站自动化组件说明在Process zone中列出开关设备（断路器、开关、隔离开关）、变压器调节部件，以及电流／电压传感与互感器等测量元件。[IEC原文](https://syc-se.iec.ch/iec-63097-smart-energy-roadmap/substation-automation-system/)

本项目据此结合采集、执行设备资料，按仿真职责归纳为四类；辅助系统纳入被监测、被控的物理侧。此划分不等同于IEC逻辑节点类别，也不要求一类对应一台实物或固定安装层。

| 过程层类别 | 实例与工程支撑 |
| --- | --- |
| 一次设备及辅助系统 | R1支持开关及变压器调节对象；R15支持有载分接调压；R16支持冷却风机／泵及温度控制；R17支持电容器、电抗器补偿支路。 |
| 感知设备 | R1/R4支持电流、电压感知，R2/R3支持状态传感与配套输入；R18支持开关机构行程、振动及线圈电流观测。 |
| 采集与处理设备 | R4支持合并单元的采样发布，R2/R3支持状态采集和专用分析。二者在仿真中归入同一功能类，实例保留不同接口。 |
| 控制接口设备 | R4支持智能终端式开关输入／输出，R15/R16支持调压与冷却控制。智能终端只作为开关支路的实例，其他对象按各自驱动接口配置。 |

断路器会改变接线通断、机构位置及动作过程；行程、线圈电流和振动有实际测量支撑（R18），但需相应传感器，不是每台断路器都原生上报。电气通断进一步影响哪些支路的电流、电压及供电状态，由接线和工况决定。温度等间接影响由负载、损耗、冷却关系计算，不直接把分闸事件映射为所有非电气量异常。

变压器分接机构调节变比和电压（R15），补偿支路改变无功交换（R17），冷却系统改变温度演化（R16）。文中的简化传导模型是据这些功能关系作出的建模选择，时间常数、幅值及测点可见性仍由实例参数和试验确定。表中类别不要求首期全部实现。

### 1.2 类别间的接口依据

| 图中连接 | 工程接口及资料依据 |
| --- | --- |
| 一次设备及辅助系统 → 感知设备 | 物理作用关系，非通信报文。R1/R2/R16/R18支持电气量、温度及机械状态的测量；只将实际部署测点的观测提供给识别。 |
| 感知设备 → 采集与处理设备 | R4支持互感器输入，R2支持Pt100／4–20 mA，R3支持IEPE等振动采集输入；输入通道按实例匹配。 |
| 采集与处理设备 → 状态监测装置 | R2/R3支持采集、分析和上传，可为数字接口或同机内部接口。 |
| 采集与处理设备 → 保护装置、测控装置 | R1/R4支持合并单元的SV发布；SV只用于对应电气采样实例，不用于全部状态传感。 |
| 保护装置、测控装置 ↔ 控制接口设备 | R4支持GOOSE开关控制；R15/R16支持调压、冷却功能及各自控制接口。保护动作只接入对应支路，普通调节不统一套用跳闸语义。 |
| 控制接口设备 ↔ 一次设备及辅助系统 | R4支持分合闸输出和位置接点；R15/R16支持分接与冷却控制。请求、设定与实际状态分别记录；联锁和动作限制按设备类型配置。 |
| 状态监测装置 → 站端监控系统 | R2/R3支持数据输出，R5支持Modbus、IEC 61850等站端接入。 |
| 保护装置、测控装置 ↔ 站端监控系统 | R1/R5支持IEC 61850报告与控制，操作请求下发至相应测控功能。 |
| 授时系统 → 需对时的设备 | R7支持PTP、IRIG-B、NTP，R4给出采集侧同步能力；按接收端匹配。 |
| 采集与处理设备 → 无线传输终端 → 无线接入网关 → 站内通信网络 → 状态监测装置 | R6支持串口／以太网与无线互联，本项目选配为状态数据替代通路。 |

油气／微水检测可由专用分析装置完成，不能等同于通用模拟输入；振动传感器的存在也不等于已证明声波攻击漏洞。

五类观测的协作背景见[系统角色设计第3.4节](系统角色设计.md#34-监测者)和[协同实施方案](课题三协同研究边界接口及仿真实施方案.docx)，具体交付字段以[数据交付规范](五类监测接口数据交付规范.md)为待确认需求。SDR的频段覆盖、IDS的协议解析以及设备的滤波、调频、拒收和补偿能力均按场景配置，不能由上述通信接口推定。

## 2. 数据可获取性

资料证明“某类设备／采集方式能够提供某类数据”，不代表全部型号、部署条件都具备该能力。JSON字段名、CSV布局、设备映射和防御动作封装是项目约定；具体监测接口与数据由协同课题组提供，本方接入时保留对应的可观测条件，交付要求见[五类监测接口数据交付规范](五类监测接口数据交付规范.md)。

| 接口 | 可获取的数据与路径 | 派生或条件数据 | 依据 |
| --- | --- | --- | --- |
| 电磁 | 接收机／分析仪采集I/Q及采集配置，适配为SigMF；实数采集保留实际采样格式 | 功率需幅度校准；带宽、中心频率、信噪比为算法估计；接收端口功率不等于设备处场强或攻击源发射功率 | R8、R9、R14 |
| 声波 | 超声麦克风＋采集卡提供PCM、采样配置和WAV文件 | 声压需麦克风灵敏度及采集链路校准；方位／位置需同步多通道或其他定位配置，单个PCM通道不保证提供 | R10 |
| 无线SDR | 匹配频段的接收机提供I/Q，驱动提供采样时间及溢出等采集状态 | 协议身份需解码，真实身份需识别；业务接收端关联来自配置，链路统计另接该端记录。采集节点不能凭空知道对端收包情况 | R8、R9；身份和链路统计的条件是本项目可观测性约束 |
| 网络IDS | EVE可记录告警和流事件；报文探针解析GOOSE/SV字段并保留报文证据 | EVE字段随事件类型变化；二层GOOSE/SV不强制填写IP和端口。设备身份靠资产映射，协议字段含义需匹配数据集配置 | R11、R13 |
| 业务量测 | 原厂采集／监测接口和IEC 61850对象提供量测、状态及可用的质量、时间信息 | 正常上下限来自配置／基线，偏差由计算得到；无法观测的实际物理量不进入识别接口；CSV为本项目导出格式 | R2–R5、R12 |

宽频可获取性分别核对：FSW26的规格范围为2 Hz–26.5 GHz，说明存在覆盖目标电磁频段的仪器，但探头、瞬时采集带宽和扫描空档仍须单独配置；不将它作为轻量底座的必选硬件。CM16/CMPA规格覆盖2–200 kHz，116H支持500 kS/s等采样率，说明超声采集存在对应实现；是否满足全频段灵敏度、校准及实时性指标仍需实测。两者均不证明本项目已经完成宽频监测指标。[R14、R10]

SV数据保留采样计数、同步状态和质量；R13的接口显式检查RefrTm是否存在，不能一律假定逐报文绝对时间可读。GOOSE中的状态号和序号用于分析变化与重发，不能等同于普通命令的事务确认。[R13]

识别结果、设备能力表及防御请求／回执属于本项目约定。R4/R5支持实际开关控制与站端操作接口，R9支持接收机调谐／增益配置；这些证据不证明设备已实现射频指纹阻断或业务补偿算法。执行反馈须来自日志、状态或后续量测，防护成功由独立评估确认。
